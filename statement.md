Project Title

Student Report:-

1. Problem Statement:

Every students need to calculate their academic results from subject marks. Sometimes manual calculation of total, percentage, highest marks, lowest marks, and grade can take time and may cause calculation errors. Here the project provides a Python program to perform these calculations automatically.

2. Scope of the Project:

This project is designed for student result analysis. This accepts a student's name and marks in five subjects and produces a simple result report.

This project includes:

At first input of student details and marks

Then total marks is calculated

Next percentage is calculated

Now caltulate highest and lowest marks

After that grade is calculated

Finally we get Pass/Fail result

This current version does not use a database, external API, or permanent data storage.

3. Target Users:

Students

Beginners learning Python

Teachers or instructors demonstrating basic programming concepts

4. High-Level Features:

Simple user input

Subject-wise marks entry

Automatic total calculation

Automatic percentage calculation

Highest and lowest mark identification

Grade determination

Pass/Fail status

Clear report display

5. Final Output:

This program should generate a clear student performance report from the entered marks and demonstrate the use of Python programming concepts.
