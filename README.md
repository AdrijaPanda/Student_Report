### Student Report Project

This is a small python project. In this project we calculate a student's result from his marks.

*What this project does:*

We will take marks of some subjects from the user, and then the program will show -
- The total marks
- The percentage
- The highest marks
- The lowest marks
- The grade
- Pass or Fail

*Which Technology used in this program:*

I used only basic things,
- Python
- List
- Function
- If-else condition
- For loop

*How to run the program:*

1. At first download the file.
2. There after open the `Student_Report.py` file in IDLE or VS Code.
3. Now run the file.
4. After that enter the student name and marks.
5. Finally it will show the full report.

* The Concepts I used here:*

- variables
- list
- function
- if-elif-else
- for loop
- sum(), max(), min()
- percentage calculation

*Objective of the project:*

The main objective of the program is to make a simple program to check student marks. It is made with Python concepts so everyone can understand it easily.
